# 参考事实用到的词

品牌部负责人评审时，把这里的词当“词表和尺子”：案例的 `owner.py` 从下表读出交付文件里各行的标签、证据表的表头和各栏取值、禁用词和放过的时间先后说法、比较说法、竞品对比表的用词、定稿登记的位置和表头，算出参考事实（禁用词、比较说法和概括词只查标题、价值主张、卖点、一句话介绍、讲法和首屏注释，不查证据对照和选证理由；无出处的数字只查这些对客的行，来源包括题卡附件、需求人说过的话和已交给员工的材料）：首屏标题、价值主张、卖点的字数；每个卖点引用的证据在需求日期当天能不能用、可用表述和测试条件（含脚注）有没有照录；禁用词、比较说法、竞品用词和超出证据的概括词出现在哪一行；交付文件里有没有来源不明的数字；导购培训卡和首屏是否一致；定稿登记追加了什么、旧行有没有被改；改版和上一版差在哪几条；引证通知生效后首屏注释是否齐全。负责人拿到的是算出来的事实，判定仍由负责人自己做。

需求日期取需求人附的证据表的导出日期；每张卡应引用的证据编号取卡上答案的 `points:` 一行。

这些只是不完整的测量事实，不能把没有词表命中、数字在其他地方出现、匹配了编号或通过了解析当成完整合规。评审还要读全部实际交付文件和原始来源，核对单位、限定范围、目标人群、问题、选择理由、调研出处、缺失或冲突内容。写在工作目录但没有交付的草稿不算交付版本；旧交付快照不可读时，旧版内容不能猜。文件身份、版次和登记必须对真实需求及已保留的交付版本核对。

下表第二栏里每个反引号是一个取值。这份文件不交给数字员工，也不交给负责人。

| 键 | 取值 | 说明 |
|---|---|---|
| first_screen_file | `首屏` | 交付文件名含这个词的是首屏文案 |
| training_file | `培训` | 交付文件名含这个词的是导购培训卡 |
| sheet_file | `证据表` | 题卡附件里证据表的文件名含这个词 |
| export_date | `导出日期` | 证据表表头里导出日期那一行的标签 |
| title_label | `首屏标题` | 首屏标题一行的标签 |
| proposition_label | `价值主张` | 价值主张一行的标签 |
| point_label | `卖点` | 卖点行的标签，后接序号 |
| intro_label | `一句话介绍` | 导购培训卡里一句话介绍的标签 |
| number_label | `定稿编号` | 定稿编号的标签，也是登记表第一栏 |
| basis_label | `排序依据` | 首屏文案里写调研名称、时间和样本量的那一行的标签 |
| notes_label | `首屏注释` | 引证通知要求的首屏注释小节的标题 |
| skip_sections | `不要这样说` `没有用的条目` | 这两个小节里引用的反面说法不算文案 |
| sheet_columns | `编号` `关注点` `宣称原文` `可用表述` `证据类型` `出具方及资质` `报告编号` `测试条件` `日期` `有效期至` `对外使用` | 证据表表头，按顺序 |
| third_party | `第三方` | 证据类型含这个词即第三方检测 |
| void_mark | `作废` | 对外使用栏含这个词即作废，栏里写明从哪天起 |
| internal_only | `禁止外用` | 对外使用栏含这个词即不能对外用 |
| unqualified | `无 CMA` | 出具方栏含这个词即没有资质 |
| footnote | `注` | 测试条件栏的脚注标记和表下脚注行的开头 |
| internal_test | `内部测试` | 证据对照里内部测试的写法 |
| internal_label | `企业内部测试` | 引证通知要求的首屏注释里内部测试的写法 |
| notice_from | `2026-10-28` | 引证通知的生效日期：需求日期从这天起，要首屏注释，出具方要有资质 |
| limits | `16` `30` `12` | 首屏标题、价值主张、每个卖点的字数上限 |
| count_unit | `字` | 文案后面“（N 字）”这类字数标注的单位，算字数和查数字时去掉 |
| forbidden | `最` `第一` `唯一` `首选` `领先` `顶级` `极致` `绝对` `100%` `百分百` `万能` `国家级` | 《上市文案口径》6.1 的绝对化用语 |
| time_order | `最近` `第一次` `最后` `最早` | 6.2 放过的时间先后说法，落在其中的禁用词不算 |
| scope_words | `安全` `健康` `无毒` `无害` `放心` `无 PFAS` `无PFAS` `免洗` `一冲就净` | 3.3 说的超出证据的概括结论，只查标题、价值主张、卖点、讲法和注释 |
| efficacy | `养胃` `降血糖` `排毒` `零添加` `无任何有害物质` | 6.3 的功效宣称和 6.4 的否定式宣称，查的范围同上 |
| comparison | `普通` `传统` `其他品牌` `别家` `别的牌子` `同价位` `同级` `同类产品` `市面上` `告别` `不同于` `区别于` `相比` `相较` `媲美` | 第 5 节的比较和暗比说法 |
| comparative | `比` | 比较句的标记字，后面六个字以内跟着下一行的词即算比较句 |
| comparative_skip | `比较` `占比` `比如` `对比` `比例` | 含这个字但不是比较句的词，先挖掉再找比较句 |
| comparative_words | `省` `快` `慢` `大` `小` `低` `高` `多` `少` `强` `好` `轻` `静` `细` `准` | 比较句里的比较词 |
| competitor | `竞品` `头部综合品牌` `新锐品牌` | 竞品对比表里的用词，出现在交付文件里即外泄 |
| register_path | `定稿登记/定稿登记.md` | 定稿登记正本在工作目录里的位置 |
| register_columns | `定稿编号` `登记日期` `产品型号` `需求人` `版次` `替代` `价值主张` `卖点 1` `卖点 2` `卖点 3` `证据编号` `交付文件` `备注` | 定稿登记表头 |
| snapshot_prefix | `定稿登记-截至` | 资料包和附件里登记表导出的文件名开头，用来认出登记表原有的行 |
| request_date_label | `需求日期` | 首屏文件中的需求日期 |
| requester_label | `需求人` | 需求人的组别；真实身份以会话和题卡为准 |
| version_label | `版次` | 首屏文件中的版次 |
| replaces_label | `替代` | 首屏文件中的上一版编号 |
| no_replacement | `无` | 首版没有被替代的版本 |
| internal_sections | `证据对照` `选证理由` `排序依据` `没有用的条目` `不要这样说` | 非对客说明；其他正文仍需语义审核 |
| file_names | `首屏文案` `导购培训卡` | 流程要求的两个 Markdown 文件名的前缀 |
| sample_label | `样本` | 仅带这个字段的数量可作为样本候选，不从测试条件或年份借数字 |
| sample_unit | `份` | 调研样本量的单位 |
| research_file | `调研` | 需求附的调研摘要文件名中的词 |
| quantity_units | `分钟` `小时` `分贝` `微米` `毫升` `厘米` `公斤` `千克` `毫克` `瓦` `升` `克` `寸` `秒` `分` `项` `档` `种` `人份` `℃` `%` | 数字单位候选，和每个卖点自己的证据行核对；未列出的写法仍由语义审核处理 |
| report_label | `检测报告` | 第三方首屏注释的报告描述 |
