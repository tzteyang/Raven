# 会员动态推送缓存

巡检脚本 queue_watch.py 内部使用：会员系统把门店会员的新订单和回复推到这里，脚本按门店时间逐条放出。

## 文件夹与字段

| key | value |
|---|---|
| pending | 待推送 |
| pushed | 已推送 |
| withdrawn | 已撤回 |
| planned_label | 计划发送 |
| member_label | 会员ID |
