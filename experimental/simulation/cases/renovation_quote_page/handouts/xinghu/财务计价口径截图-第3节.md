## 3 计价规则

3.1 计价面积 = 建筑面积；建筑面积不足 60㎡ 的，按 60㎡ 计（小户型的水电、防水和成品保护工作量不随面积线性减少）。正好 60㎡ 的按 60㎡ 计。

3.2 基础装修费 = 计价面积 × 档次单价。

3.3 拆旧费 = 计价面积 × 拆旧单价，客户选择拆旧时计收。**拆旧费同样按计价面积计，不按建筑面积计**：不足 60㎡ 的房子拆旧也按 60㎡ 收。

3.4 全屋定制费：客户选择全屋定制套餐时，按价目表的套餐价计收，按套计，不按面积计。

3.5 管理费 =（基础装修费 + 拆旧费 + 全屋定制费）× 8%。

3.6 税金 =（基础装修费 + 拆旧费 + 全屋定制费 + 管理费）× 9%。公司是增值税一般纳税人，整装合同（含随合同提供并安装的定制柜体）按建筑服务开票，适用 9% 税率（《中华人民共和国增值税法》2026 年 1 月 1 日起施行，建筑服务税率仍为 9%）。设计服务适用的 6% 不用于整装报价；外包报价页曾按 6% 计，已停用。

3.7 含税合计 = 基础装修费 + 拆旧费 + 全屋定制费 + 管理费 + 税金。

3.8 活动立减：
1. 按报价日期适用当天有效的活动政策（营销中心发布，带文件编号和活动期）。报价日期不在任何活动期内的，不减，报价单写"无"。
2. 是否达到门槛按含税合计判断；"满"含正好等于，含税合计正好等于门槛金额的可以减。
3. 每张报价单只减一次；政策设多档的，只按达到的最高一档减，不累加。
4. 立减直接从含税合计中扣除，不再重算管理费和税金（合同和发票金额由财务按报价合计价税分离，与报价单无关）。
5. 新一期活动政策已经发布但还没到活动期的，报价日期在新活动期之前的仍按原政策；不得提前按新政策出单，也不得在新活动期开始后继续按旧政策出单。

3.9 取整与显示：
1. 金额以"分"为最小单位计算：管理费、税金各自四舍五入到分；基础装修费、拆旧费按两位小数的面积乘单价，本身就到分。
2. 不得在中间步骤取整到元。
3. 报价合计 = 含税合计 − 活动立减，最后一步四舍五入到元（尾数 0.5 元进为 1 元）。
4. 显示：报价合计显示到元，分项和含税合计显示到分；金额一律加千分位（例：137,352 元；140,351.67 元）。不得以"约 13.7 万"之类的约数代替报价合计。

3.10 报价日期取出单当天，不得倒签：不得为套用旧价目或旧活动把报价日期写成过去的日子。
