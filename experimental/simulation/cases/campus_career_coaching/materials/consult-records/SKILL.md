## 1. 记录文件放在哪

共享工作目录（就是辅导助理自己的工作目录）的 `咨询记录/` 文件夹。每位学生一个文件，文件名是"学号.md"。同一位学生的多次辅导写在同一个文件里，按时间顺序，新的一次追加在末尾。文件还没有的，新建，先写学生基本信息。

系统导出的近 30 天记录只供查阅，不在导出文件上改；导出里有这位学生的记录、而 `咨询记录/` 里还没有他的文件的，新建文件写本次记录，在"上次情况"里写上次的日期和要点即可，不用把旧记录整段搬过来。

## 2. 文件格式

```markdown
# 咨询记录｜学号 姓名

- 学院/专业：……
- 年级：……

## YYYY-MM-DD 咨询类型（第 N 次）

- 咨询方式：线上 / 线下
- 辅导人：……
- 上次情况：……
- 学生诉求：……
- 事实底稿：
  - ……（出处：……）
- 本次处理：……
- 建议要点：
  - ……
- 学生待办：……
- 下次预约：……
- 转介：……
```

"第 N 次"按这位学生在中心的辅导次数算，导出记录和辅导小结里的也算。

## 3. 各栏怎么填

| 栏目 | 填什么 | 示例 |
|---|---|---|
| 咨询类型 | 简历修改、面试辅导、签约咨询、职业规划，四选一 | 简历修改 |
| 辅导人 | 辅导老师姓名，线上 AI 就业辅导助理写"AI 就业辅导助理" | 陈老师 |
| 上次情况 | 上次的日期、类型和要点；第一次来写"首次来访" | 2026-09-29 面试辅导：练自我介绍，缺结果，重答已补上 |
| 学生诉求 | 学生这次想解决什么，概括学生的原话 | 投朗衡所审计助理，10 月 31 日截止，想把简历改成一页 |
| 事实底稿 | 学生提供的事实，一条一行，注明出处（预约单、信息表、简历原稿、成绩单、证明材料、学生口述）；核实或更正过的，写核实后的说法 | 注册会计师：2025 年通过会计、税法（出处：2025 年度成绩单） |
| 本次处理 | 交付的文件名，或答复的结论 | 交付"宋佳宁-临江财经大学-朗衡所审计助理.md" |
| 建议要点 | 给学生的建议，每条一句；面试辅导写练了哪道题、指出的缺口、提纲要点、重答有没有补上 | 兼职经历和岗位无关，已删 |
| 学生待办 | 学生要做的事和时间 | 10 月 20 日前在官网完成网申 |
| 下次预约 | 日期和事项；没约写"未约" | 面试通知到后预约，练行为题 |
| 转介 | 转给谁、原因；没有写"无" | 签约窗口（行政楼 112）：违约金条款 |

## 4. 样例

### 样例一　简历修改（导出记录原文，已隐去电话）

```markdown
# 咨询记录｜2023210388 宋佳宁

- 学院/专业：会计学院 会计学
- 年级：2023 级本科（2027 届）

## 2026-09-14 简历修改（第 1 次）

- 咨询方式：线下
- 辅导人：李老师
- 上次情况：首次来访
- 学生诉求：投朗衡所审计助理，简历两页，想改成一页
- 事实底稿：
  - 临江财经大学 会计学 2023.09–2027.06，GPA 3.38/4.00（出处：信息表、成绩单）
  - 临江顺和财税服务有限公司 会计助理实习 2025.07–2025.08，录入记账凭证约 300 张（出处：信息表；数量为学生口述）
  - 会计学院学生会宣传部干事 2024.09–2025.06，负责部门公众号排版，共 26 篇（出处：任职证明写明"负责公众号排版"）
  - 初级会计专业技术资格（2025）（出处：证书）
- 本次处理：交付"宋佳宁-临江财经大学-朗衡所审计助理.md"，原稿未改
- 建议要点：
  - 教育背景移到最前，删奶茶店兼职和兴趣爱好，按模板第 7 节算是 31 行
  - 原稿"累计处理凭证上千张"学生说是估的，改为学生核实的"约 300 张"
- 学生待办：10 月 31 日前在朗衡所公众号完成网申
- 下次预约：未约
- 转介：无
```
