# 渠道与记账说明（订单台账怎么来的）

| 项目 | 内容 |
|---|---|
| 文件编号 | YH-JZ-04 |
| 版本 | 2026 年 9 月 7 日更新 |
| 整理 | 店主周禾 |
| 适用 | 每年一本的订单台账，以及看台账的人 |

## 1. 台账是什么

1.1 每年一个 Excel 文件，名字叫"订单台账"加年份，用 WPS 存的。里面三张表：点评导出、抖音导出、手记。三张表的列不一样，各管一个渠道。

1.2 台账是我自己拼的，不是哪个系统出的，所以各种写法都有。看台账的人别指望格式整齐，先理一遍再算（见《复盘做法》第 2.3 节）。

1.3 三张表的第一行是我写的说明（合并了单元格）；点评那张第二行还有一行分组标题，第三行才是列名。

## 2. 点评导出

2.1 从美团开店宝后台按下单时间导出（点评和美团是一个后台），每次复盘前把今年的订单整个重新导一遍贴进来，所以状态是导出那天的。

2.2 每一列：

| 列 | 是什么 |
|---|---|
| 序号 | 导出时的行号，没别的用处 |
| 订单号 | 16 位数字，点评/美团的订单编号 |
| 团购名称 | 平台上挂的套餐名，看关键字认套餐 |
| 下单时间 | 客人在平台上付钱的时间，对价看它 |
| 验券时间 | 客人到店、我扫码验券的时间，就是拍摄那天；没来用的空着 |
| 手机号 | 打了码，只露前三位、后四位 |
| 顾客实付 | 客人付的钱，复盘的营收看这一列 |
| 平台服务费 | 平台扣的 8% |
| 商家应得 | 实付减服务费，是平台打给我的钱，复盘不用 |
| 订单状态 | 已验券、未验券、已退款三种 |

2.3 毛病：日期有的是 Excel 日期，有的是文字（WPS 贴的时候自己转了一部分）；金额有的带".00"；退款的单服务费和应得都是 0；还没验券的那两栏空着。偶尔贴的时候会把一段贴两遍。

## 3. 抖音导出

3.1 抖音来客我只在手机 App 上看，App 里导不出表，这张是我照着手机一单一单抄的。

3.2 每一列：

| 列 | 是什么 |
|---|---|
| 订单编号 | 19 位数字 |
| 商品 | 抖音上的商品名，看关键字认套餐 |
| 支付时间 | 客人付钱的时间，对价看它 |
| 核销时间 | 到店核销的时间，就是拍摄那天；没来的空着 |
| 手机号 | 打了码，前三后四 |
| 支付金额 | 客人付的钱 |
| 状态 | 已核销、未核销、已退款 |

3.3 毛病：手抄的，日期写法最乱，有"7/5 14:22"这样不带年份的，有"2026/7/5"，有只写"7月5日"的，没写年份的都是台账那一年；金额有的写"元"，有的写成"699.0"；抄错数、点错小数点的事出过。抖音扣的 5% 服务费我没抄。

## 4. 手记

4.1 手记记的是走微信收的钱：小红书私信成交的、老客、朋友介绍的、路过进店的、点评老客加了微信以后直接找我的，还有团购客人到店加修的钱。

4.2 微信收款没有订单号，我自己编"手记-序号"，四位数，从开店起一直往下编，不分年，所以每年的手记不是从 0001 开始。

4.3 每一列：

| 列 | 是什么 |
|---|---|
| 单号 | 手记-序号；同一单的定金、尾款、退款用同一个单号 |
| 日期 | 收钱那天 |
| 客人 | 微信备注，会重名，也会前后写法不一（"王女士""王姐"） |
| 手机 | 完整号码，有的带空格或横杠；少数没留 |
| 来源 | 小红书、老客、朋友介绍、路过进店、点评老客加微信；加修行写点评或抖音 |
| 套餐 | 我的简写，"写真经典""经典写真"是一个东西；加修行写"加修" |
| 款项 | 全款、定金、尾款、加修、退款五种 |
| 金额 | 收的钱；退款是负数 |
| 备注 | 约的拍摄日、含加修几张、加修对应的团购单号、退款原因、送的给谁 |

4.4 几种单在手记里的样子：

- 写真、亲子照：交定金那天记一行（款项"定金"，备注"约几月几日拍"）；拍完收尾款再记一行，同一个单号，款项"尾款"，有加修的备注"含加修几张"。
- 证件照、当场付清的写真亲子：一行，款项"全款"。
- 团购客人到店加修：单独一行，自己一个单号，款项"加修"，备注写"点评单"或"抖音单"加团购单号、加修几张。
- 退一部分钱：一行，同一个单号，款项"退款"，金额负数，备注写原因。
- 客人取消、定金退回：也记一行退款，金额是负的 200。
- 送的、置换的：一行"全款"，金额 0，备注本该写清楚是送谁、跟谁置换，有时我忘了写。

4.5 毛病：日期有 Excel 日期，也有"3月5日""2026/3/5""2026.3.5"；金额有的是数字，有的写"元"、带千位逗号；对微信账单的时候，有过同一笔又补记一遍的。

5.2 `uploads`：我发给你的附件都在这儿，台账、上次的页面、清单都是。只看，不往里写。

5.3 `复盘`：交给我的复盘页存一份；我确认过没问题的单记在 `已核对订单-<年份>.md`，一年一个文件，格式见《复盘做法》第 3.2 节。
