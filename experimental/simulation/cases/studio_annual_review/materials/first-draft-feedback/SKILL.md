## 1. 当时交了什么

一共三个文件：

- 复盘报告网页：手机上要划十二屏，分"整体洞察、趋势分析、结构分析、异常分析、行动建议"五章；

- 汇报幻灯片：18 页。

## 2. 网页开头几段（原文照抄）

> 整体洞察：2025 年 1–9 月，工作室实现营收 24.77 万元，整体呈波动上升趋势，7 月达到峰值后出现回落，8 月为关键拐点，建议重点关注下半年的增长动能。营收数据取自各平台结算金额，更能反映真实到手收入。
>
> 趋势分析：月度营收环比波动区间为 −32.6% 至 +41.2%，2 月受春节影响为全年低点，3 月迅速反弹。以 3 个月滑动平均看，二季度增长斜率最大，置信度高。
>
> 结构分析：点评/美团渠道贡献 40.7%，微信渠道贡献 51.2%，抖音渠道贡献 8.1%，渠道集中度偏高，存在单点依赖风险。
>
> 复购分析：在 792 条有效订单记录中，有 268 条来自重复出现的手机号，复购率达 33.84%，客户粘性良好。
>
> 异常分析：按 3σ 和 1.5 倍四分位距规则，识别出 23 个离群订单，主要为 1,399 元以上的大额写真和亲子照订单，建议人工复核；另发现 41 组疑似重复记录（同一单号出现两次）。

## 3. 店主的意见（10 月 11 日晚上微信里说的，表妹记下来的）

1. 我就要一页网页，手机上看。表格和幻灯片我不看，不用做。
2. 十二屏太长了。我就问三件事：哪个月掉得最多、哪个渠道最高、复购多少。别的不用写。
3. 营收别用平台结算的钱，那是扣完服务费的。我要的是客人付了多少，退了的扣掉就行。
4. "41 组重复"大多数是定金和尾款，同一个单号两行，本来就是一单，不是重复。真重复的是同一单号、同一款项记了两次的那种。
5. 复购率 33% 不对。定金尾款算成了两条，人就像来了两次；得先合成一单再数。
6. "23 个离群订单"是什么意思？臻选和亲子照本来就贵，贵不是错。我要的是哪几笔录错了：单号多少、表上写的多少、应该多少。真正录错的那几笔你反而没列出来。
7. 金额别写"24.77 万"，写到元；百分比别带小数。
8. "拐点""置信度""滑动平均"这些词我看不懂，也用不上。每段两句话说完。
9. 9 月有几笔是交了定金、10 月才拍的，不能算进 9 月。

## 4. 对照着看

| 第一版的做法 | 店里要的 |
|---|---|
| 交三种文件 | 只交一页网页 |
| 分五章写报告 | 三件事加要改的单，一页 |
| 营收用平台结算的钱 | 营收用客人实付，扣退款，不扣服务费 |
| 一行算一单 | 定金尾款合成一单，加修跟原单 |
| 按大额、离群挑异常 | 按当时价目对账，挑录错的和记重复的，写单号 |
| 小数、"万"、术语 | 整数元、整数百分比、说人话，每段不超过两句 |
| 按收钱那天算月份 | 按拍摄那天算月份，没拍的不算 |
