## 1. 目的与依据

宣称是化妆品内容里风险最集中的地方。本表把法规要求和公司口径合在一起，审核和写作都按本表执行。依据：

- 《化妆品监督管理条例》（国务院令第 727 号，2021 年 1 月 1 日起施行）：用于染发、烫发、祛斑美白、防晒、防脱发的化妆品以及宣称新功效的化妆品为特殊化妆品，须取得注册证；化妆品的功效宣称要有充分的科学依据。
- 《化妆品功效宣称评价规范》（国家药品监督管理局 2021 年第 50 号公告，2021 年 5 月 1 日起施行）：不同功效要用人体功效评价试验、消费者使用测试、实验室试验或文献资料来评价；量化指标和宣称温和、适用敏感皮肤的，要有相应的试验或测试。
- 《中华人民共和国广告法》（2021 年修正）第九条（不得使用“国家级”“最高级”“最佳”等用语）、第十一条（引证内容要真实准确、表明出处，有适用范围和有效期限的要明确表示）、第十七条（非医疗类广告不得涉及疾病治疗功能、不得使用医疗用语）、第二十八条（虚构使用商品效果等构成虚假广告）。
- 《广告引证内容执法指南》（市场监管总局，2026 年 6 月发布）：对引证内容的出处、适用范围、有效期和检测机构资质提出细化要求。

## 2. 产品类别与可宣称的功效

2.1 特殊化妆品只能宣称注册证载明的功效，必须在内容里写注册证号的，按法规事务组的注册证通知执行。

2.2 普通化妆品只能宣称已备案的功效（见《产品备案和注册信息表》）。本公司普通化妆品一律不得出现祛斑美白类表述，包括“提亮肤色”“亮白”“去黄”，公司口径严于字面规定。

2.3 尚未取得注册证的产品，不得发布任何宣传内容，包括“新品预告”“即将上市”。

2.4 产品备案的功效以外，不得暗示其他功效；两种产品搭配使用的内容，不得让普通化妆品沾上特殊化妆品的功效。

## 3. 哪些宣称必须有依据

3.1 **量化宣称**：持续时间（“28 天”“72 小时”）、百分比、人数、“几天见效”，必须有功效评价试验依据。

3.2 **需要试验的功效**：舒缓、修护、紧致、抗皱、温和等，必须有依据表登记的人体功效评价试验、人体安全性评价或消费者使用测试，以依据表“评价方法”一栏为准。

3.3 **适用人群**：“适用敏感肌”“敏感肌可用”“孕妇可用”等，必须有人体试验或消费者使用测试；依据表里没有的，不能写，包括“敏感肌闭眼入”“敏感肌友好”“敏感肌也能放心用”这类说法。

3.4 **一般宣称**：不量化的保湿、清洁、卸妆，可以用文献资料作依据，依据表已列的可以直接写，不需脚注。

3.5 依据只看依据表和更新单。送审人说“报告马上出来”、供应商资料、原料商数据、竞品的说法，都不算依据。

## 4. 宣称怎么对依据

4.1 **对照方法**：按“产品配方 + 功效 + 指标”找依据表里的那一行，核对三件事：这份依据在计划发布日是否有效；是否覆盖该产品的配方；内容里的说法和“可用表述”是否是同一条宣称。三件都满足才算有依据。

4.2 **按配方覆盖**：依据覆盖的是配方，不是规格。配方号相同的产品，不论规格（30mL、50mL 大瓶装、旅行装）都可以使用同一份依据；配方号不同的，包括同名的升级款，不能借用。

4.3 **套装**：套装不单独做功效评价。套装内容里的功效宣称，只能落到做过评价的那一件单品上，写明是套装里的哪一件，例如“礼盒中的乳液 72 小时持续保湿*”；不能写成整个套装或“三件套”的功效。

4.4 **同义改写与换算**：功效词不变、指标换算后完全相等的，视为同一条宣称，例如“4 周持续保湿”与“28 天持续保湿”、“72 小时持续保湿”与“3 天持续保湿”，照用原依据并带脚注。改了功效词（“保湿”写成“修护”）、改了数值、或者用了不确定的时长（“一个月”“长效”“持久”）的，视为新的宣称，要另有依据。

4.5 **有效期**：依据自报告出具之日起三年内可以用于对外宣称（公司规定，依据表“有效期至”一栏已算好）。按该篇的计划发布日期判断：发布日期晚于“有效期至”的，这份依据不能用，即使审核当天还在有效期内。

4.6 **依据表更新**：依据表的更新单写明生效日期，按《内容合规审核规范》第 12 节执行：计划发布日期在生效日期之前的篇目按旧表，当天及以后的按新表；更正类更新按更新单写明的执行方式。

## 5. 引证脚注

5.1 依据表里“可用表述”带星号（*）的宣称，都来自试验数据。用了这些表述（或第 4.4 条的同义说法），同一篇正文末尾必须带依据表给出的脚注，写明样本、时长和报告编号。

5.2 一篇里有两条带星号的宣称时，用“*”“**”区分，脚注逐条写全。

5.3 脚注写在正文里，不得只放在图片角落的小字里。

5.4 不带星号的一般宣称（保湿、清洁、卸妆）不需要脚注；特殊化妆品按注册证通知写注册证号。

## 6. 禁用词与替换建议

下面四类词，审核时逐篇过一遍。A、B 类和 D 类出现即记红灯条目，C 类记黄灯条目，按“替换建议”改。

### 6.1 A 类　特殊功效词（普通化妆品不得出现）

| 词 | 说明 | 替换建议 |
|---|---|---|
| 美白 | 祛斑美白类 | 删除；改写为有依据的保湿等卖点 |
| 淡斑 | 祛斑美白类 | 删除 |
| 祛斑 | 祛斑美白类 | 删除 |
| 斑淡 | 如“斑淡了”“斑都淡了” | 删除 |
| 提亮肤色 | 公司口径按美白类处理 | 删除；需要描述肤感时写“水润”“软嫩” |
| 亮白 | 公司口径按美白类处理 | 删除 |
| 去黄 | 公司口径按美白类处理 | 删除 |
| 防脱 | 防脱发类 | 删除 |
| 生发 | 防脱发类 | 删除 |
| 防晒 | 只有取得防晒注册证的产品（清透防晒乳）可以用 | 非防晒产品删除 |

| 脱敏 | 删除 |
| 红血丝 | 删除 |
| 激素脸 | 删除 |
| 修复受损 | 删除；“修护”须另有依据 |
| 药妆 | 删除 |
| 医学护肤 | 删除 |
| 医美级 | 删除 |
| 处方 | 删除 |

| 词 | 替换建议 |

| 最佳 | 删除 |
| 最强 | 删除 |
| 最服帖 | 很服帖 |
| 最水润 | 很水润 |
| 最滋润 | 很滋润 |

| 万能 | 删除 |
| 史上 | 删除 |

### 6.4 D 类　虚构证言和无法验证的效果

具体规定见《达人与素人内容真实性要求》第 3 节。常见写法：“我妈都说……”“闺蜜都来问链接”“同事都问我用了什么”“年轻了 X 岁”“用完斑没了”、没有购买记录的“回购了 N 瓶”、没有使用记录的“亲测有效”、AI 生成的“素人实测”和使用前后对比图。出现即记红灯条目。

## 7. 常见问题

**问：“补水”和“保湿”算同一条宣称吗？**
答：算，都是不量化的一般宣称，按第 3.4 条。

**问：“水光”能用吗？**
答：“水光”是系列名，作为产品名使用可以；写成“用了就变水光肌”属于效果承诺，没有依据，按第 3 节处理。

**问：大瓶装能用小瓶做的报告吗？**
答：看配方号，按第 4.2 条。依据表的“受试样品”写的是送检时的规格，不限制同配方的其他规格。

**问：依据快到期了怎么办？**
答：看计划发布日期，按第 4.5 条。到期前送复测，新报告入表前不要排到期后的发布。

**问：“温和”需要依据吗？**
答：需要，按第 3.2 条，要有人体斑贴试验等依据；有依据时按可用表述写并带脚注。

**问：送审单里没写的宣称要不要核？**
答：要。正文、标题、话题标签、图片上的文字里的宣称都要核。
