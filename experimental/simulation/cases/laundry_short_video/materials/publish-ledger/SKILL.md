## 字段说明

| 字段 | 说明 |
|---|---|
| 发布日期 | 实际发布日期；登记新稿时写计划发布日期 |
| 账号 | "白鹭洗护"（品牌号）或"白鹭洗护老板娘"（老板娘号） |
| 稿件编号 | KB-月日-当天序号，两个账号合起来排 |
| 团购 | 团购编号加名称；同框推两个团购的两个编号都写 |
| 出镜 | 老板娘、某店店长，或"纯画面（谁配音）" |
| 开头痛点 | 《抖音口播规范》3.4 痛点表里的名称；不挂团购的通知写"—" |
| 首句 | 定稿第一句原文，不带画面标注 |
| 口播字数 | 定稿按读法计的字数 |
| 版本 | 定稿的版本号 |
| 状态 | 待拍、已发布、已下架 |
| 成交 | 截至导出时这条视频带来的团购订单数（抖音来客后台"视频带货"口径，含未核销，不含已退款） |
| 备注 | 改稿原因、特殊情况 |
