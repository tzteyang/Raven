# 合同签署与用印权限表（2026 版，保密协议部分）

| 项目 | 内容 |
|---|---|
| 文件编号 | YZ-ADM-AU-001 |
| 版本 | 2026 版，2026 年 3 月 1 日起执行，替代 2025 版 |
| 发布部门 | 总裁办（法务部会签） |
| 批准 | 总裁 |
| 适用范围 | 杭州云栈科技有限公司及云栈科技（香港）有限公司签署的保密协议。其他合同类型见本表其他部分 |

## 1. 签约主体

| 对方 | 我方签约主体 |
|---|---|
| 中国大陆境内的公司（含外资企业在境内设立的公司） | 杭州云栈科技有限公司 |
| 港澳台及境外的公司 | 云栈科技（香港）有限公司 Yunzhan Technology (Hong Kong) Limited；对方坚持与境内主体签的，由杭州云栈科技有限公司签 |

## 2. NDA 签署人

NDA 不涉及金额，由发起业务所在体系的分管副总裁签署：

| 发起部门 | 典型对方 | 签署人 |
|---|---|---|
| 国际业务部 | 港澳台及境外的渠道商、系统集成商、客户 | 国际业务副总裁 周屹 |
| 生态合作部 | 境内合作伙伴、ISV、系统集成商 | 生态合作副总裁 韩东 |
| 销售部 | 境内客户（含外资品牌在境内的公司） | 销售副总裁 王启明 |
| 产品研发中心 | 技术合作方、我方评估的技术供应商 | 首席技术官 陆源 |
| 采购与行政部 | 供应商 | 运营副总裁 方岚 |

签署人出差或休假时，由其在 OA 设置的代理人签署；没有设置代理人的，报总裁指定。

## 3. OA"NDA 签署审批"节点

1. 发起人（业务方）：上传对方签署版或拟签署文本，附合同组的初审意见或复核意见（写明台账登记号）；
2. 发起部门负责人；
3. 法务部合同组：核对拟签署文本与意见里审过的文本一致；
4. 法务经理：仅当有已批准的偏离时增加此节点，核对偏离与批准记录一致；
5. 签署人；
6. 用印：电子签章或合同专用章（第 4 节）。

初审结论为 RED、立场待定，或还有未批准偏离的 NDA，OA 不受理签署审批。

## 4. 电子签章与合同专用章

- NDA 优先使用电子签章：签署人审批通过后，由 OA 加盖合同专用章的电子签章，生成 PDF 发给对方。对方用其自己的电子签平台签署、或签字后回传扫描件，均可。
- 对方要求纸质原件的，打印后加盖合同专用章（实体章），由行政部用印登记。
- NDA 不使用公章，不由法定代表人签字。

## 5. 归档

双方签署完成后 3 个工作日内，发起人把双方签署版上传 OA 合同库；合同组在 NDA 台账里把该 NDA 最新一行的"状态"更新为"已签署（日期）"。
