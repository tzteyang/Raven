# 参考事实用到的词和尺子

`experimental/simulation/cases/regional_review_slides/owner.py` 从这里读销售运营部负责人评审时当"词表和尺子"用的东西。负责人拿到的是算出来的事实：交付页面的源码里用了哪些字体、颜色、外链、渐变和动效，按会议室投影的分辨率渲染后有没有滚动、溢出、截断、被盖住或藏起来的字，每段字实际显示多大，标题和要点有多长，页上每个数在适用的财务口径表里对不对得上，交了几个版本、改稿前后改了哪里，核数单在不在、漏了哪些数。判定仍由负责人自己做，代码不解读页面写得好不好。

下表第二栏里每个反引号是一个取值。这份文件不交给数字员工，也不交给负责人。

## 各卡的尺子
