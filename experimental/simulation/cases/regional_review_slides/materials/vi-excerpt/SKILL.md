## 1. 标准色

1.1 屏幕材料只用下表的颜色。

| 名称 | 色值 | 用途 |
|---|---|---|
| 启衡蓝（主色） | `#0B5FFF` | Logo 底色、表头底色、强调数字、条形图 |
| 深墨蓝（文字色） | `#0A1F44` | 标题和正文文字 |
| 警示红 | `#E5484D` | 只用于未完成目标的数字（完成率低于 100%、缺口金额） |
| 白 | `#FFFFFF` | 页面底色；深色底上的文字 |
| 浅灰 | `#F2F4F8` | 分区底色、表格隔行底色 |
| 分隔线灰 | `#D9DEE7` | 表格线、分隔线 |
| 说明灰 | `#6B7A90` | 来源、单位等次要文字 |

1.2 警示红不用于标题、要点文字、装饰或底色；达标的数字不用警示红。

1.3 不用渐变、阴影、发光、半透明叠色；颜色写成上表的色值，不用相近色代替。

## 2. Logo

2.1 屏幕材料用横版 Logo（标志加"启衡工业"四字），放在页面左上角，距页面上边和左边不小于 Logo 高度的一半。

2.2 在 1280×800 的屏幕上，Logo 高度 32 到 56 像素；不拉伸变形，不改颜色，不加边框和效果。

2.3 网页材料用下面的内嵌写法，直接贴进页面，不要链接图片文件或网络地址：

```html
<svg class="logo" xmlns="http://www.w3.org/2000/svg" viewBox="0 0 168 40" width="168" height="40" role="img" aria-label="启衡工业">
  <rect x="0" y="0" width="40" height="40" rx="6" fill="#0B5FFF"/>
  <path d="M8 25 L20 12 L32 25" fill="none" stroke="#FFFFFF" stroke-width="4" stroke-linejoin="round" stroke-linecap="round"/>
  <rect x="8" y="28" width="24" height="4" rx="1" fill="#FFFFFF"/>
  <text x="50" y="28" font-size="22" font-weight="700" fill="#0A1F44" font-family="Microsoft YaHei, PingFang SC, sans-serif">启衡工业</text>
</svg>
```

## 3. 字体

3.1 屏幕材料用系统字体：Windows 用微软雅黑（Microsoft YaHei），Mac 用苹方（PingFang SC），数字和字母跟随同一字体。

3.2 不用网络字体、艺术字体和仿宋楷书类字体；不用斜体中文。

## 4. 版面

4.1 白底为主，内容左对齐，左右留白各不少于页面宽度的 4%。

4.2 一屏一个主题；标题最醒目，其次是关键数字，再次是要点和表格。

4.3 表格只画横线，表头用启衡蓝底白字；数字右对齐，千位加逗号。

## 5. 禁用做法

- 渐变背景、渐变文字、霓虹和发光效果；
- 阴影、立体、玻璃质感；
- 装饰性的几何图形、波浪线、粒子背景；
- 一页上出现标准色以外的颜色；
- 改动 Logo 的比例、颜色或组成。
