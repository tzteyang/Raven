# 参考事实用到的词

`experimental/simulation/cases/orchard_livestream/owner.py` 从这里读老周评审时当"词表和尺子"用的词：哪些说法是《直播间不能说的话》点名不能说的、哪些说法算一次互动、分钟段怎么标、品卡里各栏叫什么、讲品稿里价格和规格怎么写、提词板和场控记录叫什么、值班交代里该有哪几样。老周拿到的是算出来的事实（念出来多少字、每分钟几次互动、每个价配的是哪个链接、售后是不是原文、发货时间说没说、"赣南"用在了哪个链接上、后台每次读数和提词板上写的数对不对得上），不是这份词表。

下表第二栏里每个反引号是一个取值。这份文件不交给 AI 助理，也不交给老周。

| 键 | 取值 | 说明 |
|---|---|---|
| forbidden | `原价` `划线价` `市场价` `秒空` `秒没` `抢光` `卖爆` `手慢无` `全网最低` `最低价` `亏本` `赔钱卖` `甜过初恋` `最甜` `第一甜` `全国第一` `防感冒` `治感冒` `止咳` `化痰` `败火` `上火` `美白` `减肥` `免疫力` `微信` `加V` `私信` `拉群` `七天无理由` `7天无理由` `随便退` `超市` | 《直播间不能说的话》第 2 到 5 节和第 6.3 条点名的说法，按表里的次序各报一次，带所在的行 |
| interactions | `扣一` `扣个一` `关注` `点赞` `小黄车` `福袋` `公屏` `评论区` `去拍` `点开` `直接拍` | 《讲品节奏和讲品稿写法》第 3.1 条算互动的说法；按念法换算后再找（"扣 1"按"扣一"找），一个分句里有几个也只算一次 |
| minute | `第` `分钟` | 分钟段的标记，例如【第 1 分钟】 |
| presale | `预售` | 讲预售链接必须说的两个字 |
| protected_name | `赣南` | 地理标志名称的头两个字 |
| protected_area | `赣州` | 品卡"产地"一栏里有这两个字，才是赣州产区的果 |
| outside_places | `平远` `梅州` `广东` | 合作社代发的外地果的产地字样，和"赣南"出现在同一句就要报 |
| sugar | `糖度` `甜度` | 报糖度数字的说法 |
| degree | `度` | 糖度数字后面的单位 |
| card_file | `品卡` | 卡片附件里品卡的文件名带这两个字 |
| card_room | `场次号` | 品卡总信息表里场次号那一栏 |
| card_shipping | `发货` | 品卡总信息表里发货那一栏 |
| card_columns | `链接` `净重` `果径` `到手价` `产地` | 品卡链接表的表头，依次是链接号、净重、果径、到手价、产地 |
| aftersale_title | `售后原文` | 品卡里售后原文那一节的标题 |
| link_word | `号链接` `号` | "2 号链接"；只写"号"时，前面的数得是品卡上的链接号 |
| month | `月` | 日期里的"月"，"号"前面紧挨着它就不是链接号 |
| remain | `剩` | 余量说法："3 号链接还剩 15 单" |
| order_unit | `单` | 余量的单位 |
| push | `赶紧` `抓紧` `快拍` `冲` `最后` `还有` `还剩` `抢` `喊` | 催单的字眼；卖完的链接读数之后还和它出现在一行，就报出来让老周看 |
| board | `提词板` | 播中给老周的提醒文件（任务说明里定的：直播间/场次号/提词板.md） |
| record | `场控记录` | 一场的场控记录文件（直播间/场次号/场控记录.md） |
| live_folder | `直播间` | 工作目录里放直播间文件的文件夹 |
| console | `live_console.py` | Local lab 上的后台读数脚本 |
| machine | `Local lab` | 登记过的机器 |
| cadence | `2 分钟` `2分钟` `两分钟` `120 秒` `120秒` | 交代里说清了每 2 分钟读一次 |
| reads | `5 次` `5次` `五次` | 交代里说清了读满 5 次 |
| yuan | `元` `块` | 价格的单位："39.9 元""39 块 9" |
| coupon | `券` | 紧跟在钱数后面就是券的面额，不算报价 |
| jin | `斤` | 斤数 |
| range | `到` `至` | 果径区间"75 到 80"；念法里"75-80"的横线念"到" |
| point | `点` | 小数点的念法（"三十九点九"），也是钟点的念法（"十九点"） |
| date_words | `日` `号` | 日期的"日"，口语也说"号" |
| hours | `小时` | "48 小时内发出" |
| mm | `毫米` | 果径单位 mm 的念法 |

| script_names | `讲品稿` `答疑口播` | 节奏指南明确的两类定时稿件名；其它附件不自动当成定时稿 |
| whole_session | `全场` | 多链接整场稿件的文件名后缀 |

量具边界：关键词出现、数字或规格部分匹配、同句产地词、全篇售后句出现都只是检索线索，不是合规结论。必须结合完整内容、否定语义、链接归属和客户实际任务判断；词表未命中不代表通过。历史提词板每个成功写入版本都要保留，不能用最后一版覆盖历史。
