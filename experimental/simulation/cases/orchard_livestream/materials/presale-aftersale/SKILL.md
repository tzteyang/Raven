## 第 1 节 今年的情况

1.1 园里种的是纽荷尔脐橙。今年 10 月 8 日开始预售，果还挂在树上。

1.2 什么时候开采，以赣州当年发的开采通知为准。通知没出来之前，不说具体哪天开摘、哪天到货。

1.3 预售名额是按园里估的产量分到每个链接的，卖完就是卖完，后台读数里看得到。

1.4 预售第一周（10 月 8 日到 14 日）是首发价，10 月 15 日起小魏按小店后台调价。价钱以当场品卡为准，不跟观众比前后两周的价。

## 第 2 节 预售怎么说

2.1 讲预售的链接，必须说"预售"两个字，并把发货时间照品卡"发货"那一栏说出来。本园今年的统一说法是：**开采后按付款先后 48 小时内顺丰发出，最晚 X 月 X 日前发完**。"最晚哪天"每场的品卡写的可能不一样（越晚下单的场次，最晚日期越往后），照当场品卡说。

2.2 不说"明天发""现摘现发马上到""三天到家"。到货看快递，不替快递打包票。

2.3 观众问"能不能指定哪天发"：不能指定，按付款先后发，最晚哪天前发完照品卡说。

2.4 合作社代发的链接，发货时间、快递照品卡上那个链接自己的写法说，不套本园的。

## 第 3 节 发货和不发地区

3.1 本园发顺丰，包邮，到手价里含运费。

3.2 不发地区照品卡说。今年默认是：新疆、西藏、青海、内蒙古、宁夏、甘肃、海南，以及港澳台。这些地方路远，脐橙路上坏得多，顺丰时效也保不住。小店后台已经设了这些地方下不了单。

3.3 被问"新疆能发吗"：直说不发，别让人去拍。

## 第 4 节 坏果怎么赔

4.1 售后照品卡"售后原文"念，一个字不改。本园今年的原文是：

> 坏果包赔：签收后 48 小时内拍照（坏果和快递面单一起拍）联系客服，坏几个赔几个。

合作社代发的链接，售后原文由合作社定，另写在品卡上，以品卡为准。

4.2 为什么一定要念全：去年 12 月有 3 单签收四五天后才说有坏果，直播里只说了"坏了包赔"，没说 48 小时，周嫂跟人扯了一个礼拜。念全了，大家心里都有数。

4.3 "赔"是按坏的个数，从实付里折算退款，客服处理；整箱坏一半以上的，客服登记补发。这些是客服的事，直播里不展开，念原文就行。

4.4 生鲜不适用七天无理由退货。《消费者权益保护法》第二十五条规定网购可以七天无理由退货，但把"鲜活易腐的"商品排除在外。所以：
- 不说"七天无理由""不满意随便退""拆了也能退"；
- 被问"能七天无理由吗"：说"生鲜不支持七天无理由，坏果照售后原文赔"，再把原文念一遍。

## 第 5 节 常被问的怎么答

| 被问 | 口径 |
|---|---|
| 什么时候发货？ | 预售，开采后按付款先后 48 小时内顺丰发出，最晚 X 月 X 日前发完（照品卡） |
| 哪天能到？ | 不报到货日；照品卡说最晚哪天前发完，到货看快递 |
| 坏了怎么办？ | 念售后原文 |
| 能七天无理由吗？ | 生鲜不支持七天无理由，坏果照售后原文赔 |
| 是赣南的吗？ | 本园的：是，产地江西赣州信丰；合作社的：照实说产地 |
| 新疆、海南能发吗？ | 照品卡的不发地区说，不发 |
| 能开发票吗？ | 能开，拍下后点店铺客服留开票信息，发货后开 |
| 送人能不能不放价格单？ | 能，下单时备注"送礼不放单"，客服看到会处理 |
| 下单后能改地址吗？ | 发货前点店铺客服改，发货后改不了 |
| 甜不甜，多少度？ | 预售期不报数，开采后直播间现场测 |
| 能加微信吗？ | 有事点店铺客服 |
