# 交付前品牌一致性检查清单（市场部，V1，2026 年 10 月起执行）

每份对外文件（提案、平台文案和其他任何对外材料）在交付前过一遍本清单，守望报告另按《品牌规范》第 6 节；每季度按第 4 节做一次渠道巡检。

## 1. 语言检查

- [ ] 定位口径与《品牌规范》第 1 节逐字一致，没有自称"搜索工具"。
- [ ] 同一句口号在全文逐字一致；文件开头单列"口号：……"（定稿口号，或"候选，待签字"）。
- [ ] 没有《品牌规范》第 2 节的禁用表述及其变体，没有点名竞品比较。
- [ ] 每个数字在同一行注明来源；没有来源的数字已删掉或写"暂无数据，待市场部确认"。
- [ ] 品牌名称和产品术语写法统一（例如"AI 全能助手"不写成"全能 AI 助手"），中英文之间空格、全半角标点统一。
- [ ] 语气符合《品牌语调与信息框架》第 4 节对应平台的要求。

## 2. 信息检查

- [ ] 主信息与《品牌语调与信息框架》第 5 节一致。
- [ ] 每条支撑信息都有证据。
- [ ] 同一份文件里的行动号召（下载、试用、关注）说法一致。
- [ ] 能通过《品牌语调与信息框架》第 6 节的信息五问。

## 3. 视觉检查（文件含图片、页面或海报时）

- [ ] 使用设计组提供的当前版本标志，没有自行变形、改色。
- [ ] 颜色只用品牌色板，文字与背景对比清楚。
- [ ] 字体、字号层级按设计组模板。
- [ ] 图片风格与品牌一致，没有来源不明的素材。

## 4. 渠道巡检表（每季度）

| 渠道 | 检查什么 |
|---|---|
| App Store 与各安卓商店 | 应用名、副标题、首句介绍是否为新定位，截图文案是否逐字一致 |
| 公众号 | 简介、自动回复、菜单文案 |
| 小红书、抖音、B 站 | 主页简介、头图、置顶内容 |
| 合作与投放素材 | 是否还在用旧定位"AI 搜索工具"的素材 |

## 5. 常见问题与修正

| 问题 | 修正 |
|---|---|
| 口号出现变体 | 全文替换为定稿口号或"候选"口号的原文 |
| 夸张词、极限词 | 换成可验证的具体功能或场景 |
| 数字没有来源 | 补来源；补不上就删掉 |
| 新旧定位混用 | 统一为"AI 全能助手"的定位陈述 |
| 各平台主信息不一致 | 回到信息层级，只改下层说法 |

## 6. 检查结果怎么写

- 逐项标"通过、不通过、不适用"；不通过的项写出原文和修改后的写法。
- 检查记录跟文件一起放进工作目录，文件名 `check-<原文件名>`。
- 发给对方的消息只写结论：通过了没有、改了几处、还有什么要对方决定（《品牌规范》第 5 节）。
