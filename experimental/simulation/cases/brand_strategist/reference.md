# 参考事实用到的词

`experimental/simulation/cases/brand_strategist/owner.py` 从这里读市场负责人评审时当"词表和尺子"用的词：哪些是《品牌规范》第 2 节的禁用表述、文件里口号行怎么标、带什么单位的数字算需要来源的数字、同一行里出现什么就算标了来源、守望报告的文件名前缀。负责人拿到的是算出来的事实（命中了哪些词、口号是否逐字一致、哪些数字没有来源、守望留下了什么证据），不是这份词表。

下表第二栏里每个反引号是一个取值。这份文件不交给数字员工，也不交给负责人。

| 键 | 取值 | 说明 |
|---|---|---|
| forbidden | `第一` `最好` `最强` `最快` `最全` `唯一` `顶级` `国家级` `全网` `全国领先` `行业领先` `100%` `绝对` `史上` `永久` | 《品牌规范》第 2 节的禁用表述，按出现次序各报一次 |
| slogan_marker | `口号：` `口号:` | 文件里口号行的开头；一份文件里出现多个不同的值即口号不一致 |
| figure_units | `万` `亿` `%` `％` | 数字后接这些单位才算"数字"（《品牌规范》第 3 节要求标来源的那种） |
| source_marks | `来源` | 数字所在行里出现这个词即算标了来源 |
| report_prefix | `watch-report-` | 守望报告的文件名前缀（守望说明规定的 `watch-report-<日期>.md`） |
