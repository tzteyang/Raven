## 1. 案例库是干什么的

客户愿意让我们讲他们的成果，是对我们的信任，也是有边界的：讲哪个数、能不能说出名字、能讲到哪天，都在客户签的《案例使用授权书》里写着。案例库把这些边界整理成一张表。对外说到客户成果时，只能用表里的内容，不能凭印象、旧邮件或别人的转述。

## 2. 字段说明

| 字段 | 含义 |
|---|---|
| 编号 | CS-两位数字，长期不变；作废的编号不再复用 |
| 行业 | 注塑、压铸、机加工，与 CRM 的"行业"字段同一口径；冲压、热处理等单列 |
| 细分 | 客户的主要产品，仅供参考，挑案例时不按细分 |
| 客户（内部） | 客户全称，只供内部识别，对外一律不用这一栏 |
| 生产地 | 接入我们系统的工厂所在地 |
| 设备台数 | 接入时客户该工厂的主要生产设备台数（注塑机、压铸机，或加工中心与数控车床合计） |
| 年用电（万千瓦时） | 接入前一年的年用电量，来自客户电费单 |
| 上线 | 系统上线的年月 |
| 对外口径（原文照用） | 授权书里客户同意对外说的那句话，数字和期限一个字都不改 |
| 数据来源 | 电费单同比：接入后的电费单与上一年同期对比，客户财务确认；系统读数：我们平台的计量读数，接入后与接入首月对比；电费单：需量电费按电费单逐月核对 |
| 授权 | 可点名、仅匿名、不可外用，见第 3 节 |
| 授权到期 | 授权书的截止日；到期当天仍可用，次日起不可外用，除非市场部发了续签通知 |
| 对外称呼 | 对外提到这家客户时的写法：可点名的是客户同意的简称，仅匿名的是"一家某某厂"的固定说法 |
| 近 90 天引用 | CRM 跟进记录里登记的引用次数，只反映用得多不多，不代表合适 |

## 3. 授权状态

3.1 **可点名**：可以说出"对外称呼"一栏的名字，和"对外口径"一起用。

3.2 **仅匿名**：只能用"对外称呼"一栏的说法，例如"一家汽车配件注塑厂"。不写客户名字，不写所在城市，不写"某知名车企供应商"这类能让人猜出是谁的描述。客户的同行、上下游大多在长三角，一个城市名加一个细分行业，往往就能对上是哪一家。

3.3 **不可外用**：客户没有签授权或只同意内部参考。这些案例保留在库里，是给销售了解行业水平用的，任何对外场合都不能提，包括电话里"顺嘴一说"。

3.4 **到期与撤回**：授权到期后客户没有续签的，按不可外用处理，导出表里仍保留原来的授权状态和到期日，以到期日为准。客户要求提前撤回的，市场部发《案例库授权变更通知》，通知写明生效日；生效后，通知优先于导出表。

## 4. 怎么挑、怎么写

挑哪一条、怎么写进信里，按《开发信与触达规范》第 3.4 节：同行业，规模（设备台数）最接近，授权可用；只引一条；数字照"对外口径"原文，后面括号注明数据来源。

两个常见的走样：
- 把"接入 6 个月电费下降 11%"写成"半年省了一成多电费"或"电费降了 10% 以上"：期限和数字都被改写了，客户没有同意过这句话。
- 把两条案例拼成一句"同行普遍下降 8% 到 11%"：这是我们自己算的，不是哪一家客户的成果。

## 5. 版本与变更

5.1 市场部每季度导出一次完整的案例库；两次导出之间的变更（新增、撤回、续签）以《案例库授权变更通知》发布，编号按年流水。

5.2 用案例前，看最新的导出表，再看导出之后发布的变更通知。通知与导出表不一致时，以已生效的通知为准。

5.3 对授权有疑问的，问市场部林楠，不要自己判断"应该没问题"。

## 6. 常见问题

**问：近 90 天引用最多的那条，是不是最保险？**
答：不是。用得多只说明适合它的客户多，挑哪一条还是看行业、规模和授权。

**问：客户口头说过"你们可以讲我们的名字"，但库里是仅匿名，能点名吗？**
答：不能。以授权书和本库为准，客户愿意改的，请他签补充授权，市场部更新后再用。

**问：对方规模和两条案例差得一样多，怎么选？**
答：可点名的优先；都可点名或都仅匿名的，选上线时间新的。

**问：电话里引用案例也要按这些规则吗？**
答：要。授权管的是对外说，不分邮件、电话还是当面。
