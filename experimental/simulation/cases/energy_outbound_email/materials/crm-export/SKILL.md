## 1. 线索表字段

| 字段 | 含义 |
|---|---|
| 客户编号 | KH-年月加两位流水，唯一 |
| 公司 / 简称 | 公司全称；简称用于标题和内部沟通 |
| 行业 | 注塑、压铸、机加工，与案例库同一口径 |
| 生产地 | 工厂所在地（不是注册地） |
| 设备台数 | 现有主要生产设备台数，销售拜访或对方资料核实后填写；扩产中的新增台数不计 |
| 年用电（万千瓦时） | 对方提供或从公开资料估算的年用电量 |
| 联系人（职务） | 我们已经有正当联系方式的关键人；同一公司有多人的只列主联系人 |
| 邮箱 / 联系方式来源 | 邮箱和它的来源（名片、展会、研讨会报名、官网），来源不明的不录 |
| 归属 | 这家客户归哪位销售；空着的是公海 |
| 最近跟进 | 最后一次跟进记录的日期（电话、邮件、拜访都算），没有记录的为"—" |
| 跟进摘要 | 最近一次跟进的内容 |
| 状态 | 未跟进、跟进中、暂停、已签约、竞品在用、集团采购、勿扰 |

## 2. 怎么查归属

2.1 先按公司全称或简称在线索表里找到这家；找不到的，说明 CRM 里还没有，按公海处理。

2.2 看"归属"：是提出请求的销售本人，或空着，可以继续；是别的销售，再看"最近跟进"：距今 90 天以内（含第 90 天）的是撞单，按《开发信与触达规范》第 2.3 节处理；超过 90 天的可以触达，登记时注明原归属。

2.3 同一集团的几家工厂分开登记、分开算归属。线索表"跟进摘要"里提到母公司或集团对接的，以本条记录的归属为准。

## 3. 怎么查勿扰

3.1 勿扰名单按公司全称登记。"范围"是"公司"的，该公司所有联系人都不触达；是"联系人"的，只对名单上那一位不触达。

3.2 线索表"状态"为"勿扰"的，勿扰名单里一定有对应记录；以勿扰名单为准。

3.3 当天新加入勿扰的（写在 `CRM待录入/勿扰新增.md` 里、还没录入系统的）同样生效，查的时候两处都要看。

## 4. 注意

- 导出表是早上 8:30 的快照。销售转来的回信、新的跟进，比导出表新，以销售给的为准，并补登记。
- 不要把导出表整份转发给公司以外的人；给客户的信里只出现对方自己的信息。
