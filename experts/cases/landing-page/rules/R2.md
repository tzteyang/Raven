# 青叶茶事｜品牌预订页工作规则

## 1. 内容来源
本次只使用内容.json；旧稿（如果提供）只是待改设计，不是规则。店名、主标题、简介、每款产品名称和价格、截止说明、自提说明、预订方式均照内容.json原样显示，允许增删空格，不改写其他文字。
每款产品显示一次，每款名称和自己的价格放在同一张卡片或同一行。不得增加未提供的价格、折扣、产品或承诺。
把主标题放在h1里；店名用文字标志；整个主要内容放在一个main元素中。主操作用一个链接或按钮，文字只写“查看预订方式”。预订方式写在页面内，无需真的联网下单，也无需二维码。

## 2. 品牌与字体
只可用这五种颜色：主色#245546、底色#F0F4E8、墨色#24312B、装饰色#AAB97D、白色#FFFFFF。颜色大小写和RGB写法不限。
装饰色只用于边框、线条和非文字图形，不能做任何文字色或大面积背景。没有画出来的CSS变量不算用色；透明底本身不算颜色。
颜色按浏览器实际显示的颜色计算，透明前景、背景和祖先opacity叠加出的新颜色也算用了该颜色；忽略字形边缘抗锯齿产生的像素。
所有可见文字与其实际背景的对比度至少4.5:1，大字不例外。图形里的文字也算文字，不用文字透明度降低对比度。
h1至h6标题的font-family列表第一项必须是“Georgia”；其他文字第一项必须是“Arial”。字体可带通用回退项；本机无此字体时允许回退，不下载字体。

## 3. 页面表现
不使用渐变、box-shadow、text-shadow、filter、backdrop-filter和非normal的mix-blend-mode。主按钮四个角圆角都为0px。
不引用外部资源、框架、字体或脚本，不写JavaScript；不用图片、canvas、视频和iframe。可用内联SVG画非文字图形，但SVG的填充和描边仍须遵守颜色规则。不要用伪元素生成任何文字。

## 4. 布局
手机检查视口为390×700，桌面为1440×900（单位px）。两种宽度都不得横向滚动，必需文字不能被裁切、隐藏或被别的元素覆盖。页面可以纵向滚动。
“手机首屏”指打开页面、尚未滚动时0到700px的范围，要求的价格和主按钮必须完整落在范围内，并可见。
全部产品的价格都必须在手机首屏；不要求显示产品状态。
手机店名字样放在页顶110px以内（整个标志底边不超过此值），店名字样的水平中心距视口中心不超过8px。桌面main实际宽度不超过920px，并水平居中，两侧空白差不超过2px。

## 5. 交付
只交一个完整HTML文档。方案一：写landing.html文件，回复正文只可为空、“已完成：landing.html”或一个单行Markdown文件链接。方案二：回复只含一个标为html的代码块，里面放完整文档。
两种方案选一种，交付前后不加设计说明、核对清单或开场白。前后额外文字只在交付格式记一处，其中的颜色、数字、产品词不在页面内容项重复记。
